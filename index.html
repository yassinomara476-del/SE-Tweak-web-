HELP CENTER

Good to know.

Does SE Tweaker guarantee 120 FPS?

No. Actual FPS depends on CPU/GPU performance, thermal limits, RAM, drivers, GameLoop configuration and the game version. The FPS selector is a target recommendation, not a promise or an automatic change to game limits.

Does it need internet all the time?

The core optimizer and free tools run locally. Internet is used for first activation, periodic license checks and optional update checks. A short offline grace period is available after a successful validation.

Can it break my Windows installation?

The current optimizer does not disable Windows services, Defender or edit system Registry values. The free cleaner touches only old files under the signed-in user's Temp folder. As with any system utility, use restore options and review prompts.

How do I get new updates?

Updates are separate from the use license. Ask the administrator to add an update entitlement; the app then checks the release information and opens its HTTPS download page.

What activity does the admin see?

The service records activation/launch heartbeats, the one-way device fingerprint, app version, timestamps and connection IP for licensing and abuse prevention. Offline app sessions cannot be reported until the device reconnects.
