Product scope

SE Tweaker is a Windows utility designed for Windows 10/11 and Tencent GameLoop. Available functions depend on the version supplied. The current optimization routine temporarily changes the process priority of supported running GameLoop game processes and saves a restore record. Free tools can clean old files in the signed-in user's Temp folder and export relevant Tencent Registry keys as a backup; the free tools do not edit Registry values.

No guaranteed FPS or performance result

Results depend on computer hardware, drivers, thermals, memory, GameLoop settings, game updates and background workloads. FPS target controls are recommendations and do not guarantee a specific frame rate or eliminate lag. Do not use the utility to bypass game security, modify game files, inject into the game or violate Tencent/game rules.
